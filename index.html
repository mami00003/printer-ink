プリンターインク 型番逆引き

プリンターのインク、どの型番を買えばいいのか

キヤノン・エプソン・ブラザーのインク 224件と、本体型番からの逆引き 229機種。公式に横断した一覧がない標準↔増量の対応 60組を、1枚の表にまとめています。

  1. 本体型番 → インク（229機種）
  2. 標準 ↔ 増量の対応表（60組）
  3. 間違えやすいところ
  4. エプソン A1 / A2 の対象型番
  5. インク一覧（224件）
  6. 価格と出典についての但し書き
1

標準と増量（大容量）は別の型番です。同じ色でも末尾に XL や -L が付くだけで中身の量が変わります。公式に横断した一覧がないので、60組を1枚の表にまとめました。

2

エプソンにはA1 / A2 が付いた仕様変更品があります。2006年発売の5機種は本体の更新が必要で、更新しても使えない型番が2つあります。

3

キヤノンの6色パックが使えるのは TS8130 / TS8230 / TS8330 / TS8430 の4機種だけです。5色パックが使える17機種のうち、13機種はグレーを積んでいません。

エプソンは一部のインクを仕様変更し、型番の末尾に A1 または A2 を付けました。46番・50番・61番・62番・65番・79番・88番が対象です。

「また、2006年発売のプリンターは、本体のファームウェア更新が完了した後におきましても変更品カートリッジ（インク型番末尾A2）のライトシアンインク「ICLC50A2」、ライトマゼンタインク「ICLM50A2」はご使用いただけません。」

キヤノンの価格は、どのページを見るかで違う

同じ型番でも、参照した本体ページによって税込価格が違いました。たとえば BCI-331BK は TS8530 のページで ¥1,420、TS8730 のページで ¥1,380。BCI-381+380/6MP は本体ページで ¥7,810、インク個別ページで ¥7,440。このサイトは、食い違ったものは価格を空にしています。買う前にインク個別ページで確認してください。

エプソンの「機種別インク型番FAQ」は機械で読むと間違える

faq2.epson.jp の機種別インク型番FAQ（id=2426）は、プログラムで読み取ると表の列がずれて、公式の個別ページと矛盾する答えを返します。たとえば EW-452A が IC1BK02 と出ますが、正しくは MUG-BK/C/M/Y です。このサイトは、機種ごとの消耗品ページとインクごとの個別ページだけを使っています。

「増量」と「大容量」はメーカーによって言い方が違う

キヤノンは標準／大容量／小容量、エプソンは標準／増量（黒だけ増量、という商品もあります）、ブラザーは標準容量／大容量。言い方が違うだけで、どれも「同じ色で中身の量が違う」という話です。
