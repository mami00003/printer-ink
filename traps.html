プリンターインク型番逆引き ／ 間違えやすいところ

プリンターインクで間違えやすいところ

キヤノンの6色パックが使えるのは4機種だけ。型番が連番でも中身は別。エプソンのA1/A2。ブラザーの1文字違い。公式の記載で確認できたものだけを並べました。

公式の記載で確認できた「間違えやすい」ところ

エプソン ― A1 / A2 が付いた仕様変更品

エプソンは一部のインクを仕様変更し、型番の末尾に A1 または A2 を付けました。46番・50番・61番・62番・65番・79番・88番が対象です。

2006年発売の PM-A820 / PM-A920 / PM-G850 / PM-D870 / PM-G4500 は、本体のファームウェア更新をしないと変更品が使えません。

「また、2006年発売のプリンターは、本体のファームウェア更新が完了した後におきましても変更品カートリッジ（インク型番末尾A2）のライトシアンインク「ICLC50A2」、ライトマゼンタインク「ICLM50A2」はご使用いただけません。」

つまり ICLC50A2 と ICLM50A2 だけは、更新しても使えません。更新の申し込みについてエプソンは「2025年3月31日（月）17:30までのお申し込みで終了となります。」と書いていて、この期限はすでに過ぎています。

エプソン インクの仕様変更　79番の変更（2023/9/14）

キヤノン ― 5色パックと6色パックはグレーの有無

BCI-381+380/5MP（¥6,520）は BK/C/M/Y + PGBK の5本。BCI-381+380/6MP（¥7,440）は、ここにグレー(GY)が足された6本です。

5色パックが使えるのは17機種。6色パックが使えるのは TS8130 / TS8230 / TS8330 / TS8430 の4機種だけです。残りの13機種はグレーを積んでいないので、6色パックを買っても1本余ります。

同じ構造が BCI-371+370、BCI-351+350、BCI-331+330 にもあります。

5色パック　6色パック

キヤノン ― 型番が連番でも中身が別

PIXUS TS8130 / 8230 / 8330 / 8430 は BCI-381/380、TS8530 / 8630 / 8730 は BCI-331/330。本体の型番は続いていますが、インクに互換はありません。

TS7330 / 7430 は BCI-381/380、TS7530 は BCI-301/300。

XK90 は XKI-N11/N10（5色+PGBK）、XK120 は XKI-N21/N20（4色+PGBK）、XK500 は XKI-N21/N20（5色+PGBK）。同じ N21 系でも XK120 には PB がありません。

TS8130　TS8530　XK120

ブラザー ― 1文字違いで別物

LC411 と LC416 は1文字違いですが別物です。DCP-J915N / J926N は LC411、DCP-J4143N / MFC-J4540N は LC416。LC411 に大容量(XL)はなく、LC416 には XL があります。

LC3117 と LC3119 は、同じ機種（MFC-J6980CDW など）の標準と大容量です。番号が変わるのに同じ機種用です。

LC3111 は A4機（DCP-J973N など）、LC3117 / LC3119 は A3機（MFC-J6980CDW など）。見た目は近いですが互換はありません。

DCP-J915N 消耗品　MFC-J4540N 消耗品　MFC-J6980CDW 消耗品

エプソン ― エコタンク機は黒とカラーで愛称が違う

EW-M634T と EW-M5610FT は、黒が YAD-BK（ヤドカリ・127ml）、カラーが HAR-C / HAR-M / HAR-Y（ハリネズミ・70ml）。1台の中で2つの愛称が混ざっています。

EW-M634T　EW-M5610FT

価格と出典についての但し書き

価格が出せるのはキヤノンだけ

エプソンとブラザーは公式がオープンプライス／オープン価格としていて、メーカーのサイトに金額が出ません。このサイトも金額を書いていません。キヤノンだけは税込価格が公式に載っています。

出典

キヤノンの価格は、どのページを見るかで違う

同じ型番でも、参照した本体ページによって税込価格が違いました。たとえば BCI-331BK は TS8530 のページで ¥1,420、TS8730 のページで ¥1,380。BCI-381+380/6MP は本体ページで ¥7,810、インク個別ページで ¥7,440。このサイトは、食い違ったものは価格を空にしています。買う前にインク個別ページで確認してください。

出典

エプソンの「機種別インク型番FAQ」は機械で読むと間違える

faq2.epson.jp の機種別インク型番FAQ（id=2426）は、プログラムで読み取ると表の列がずれて、公式の個別ページと矛盾する答えを返します。たとえば EW-452A が IC1BK02 と出ますが、正しくは MUG-BK/C/M/Y です。このサイトは、機種ごとの消耗品ページとインクごとの個別ページだけを使っています。

出典

「増量」と「大容量」はメーカーによって言い方が違う

キヤノンは標準／大容量／小容量、エプソンは標準／増量（黒だけ増量、という商品もあります）、ブラザーは標準容量／大容量。言い方が違うだけで、どれも「同じ色で中身の量が違う」という話です。

出典

純正以外について、ブラザーが書いていること

「ブラザー純正品以外の消耗品（トナーカートリッジ・インクカートリッジ等。詰替え商品含む。）を使用したことによる故障は、保証期間内や保守契約期間中でも有償修理となります」。保証の話であって、使えない・壊れるとは書かれていません。
